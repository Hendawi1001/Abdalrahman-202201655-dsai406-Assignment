# MNIST GAN Training Pipeline

This repository contains a PyTorch implementation of a Generative Adversarial Network (GAN) designed to generate handwritten digits using the MNIST dataset. It also includes an automated CI/CD pipeline configured via GitHub Actions to validate the code on every push.

## Project Structure

* **`202201655.py`**: The main PyTorch training script. It defines the Generator and Discriminator architectures, trains the model, and outputs a sample generated image alongside the saved model weights.
* **`requirements.txt`**: A list of Python dependencies required to run the project.
* **`.github/workflows/ml-pipeline.yml`**: The GitHub Actions workflow file that automates environment setup, linting, and basic dry-run testing.

## Getting Started

### 1. Prerequisites
Ensure you have Python 3.10 or later installed. It is highly recommended to use a virtual environment.

### 2. Install Dependencies
Install the required packages using `pip`:
```bash
pip install -r requirements.txt
```

### 3. Download the Dataset
This script requires the MNIST training dataset in CSV format. You must download `mnist_train.csv` and place it in the root directory of this repository before running the script.

### 4. Run the Training Script
Execute the Python script to start training the GAN:

```bash
python 202201655.py
```

### Outputs
after successful execution, the script will generate the following files in your root directory:

- `generator_model.pth`: The trained weights for the Generator.
- `discriminator_model.pth`: The trained weights for the Discriminator.
- `generated_sample.png`: A sample 28x28 grayscale image generated by the model after training.

**Pipeline Steps:**

- **Checkout Repository:** Retrieves the latest code.
- **Setup Python:** Initializes a Python 3.10 environment.
- **Install Dependencies:** Installs packages listed in `requirements.txt`.
- **Model Dry Test:** Executes a basic Python command to ensure PyTorch is installed and the environment is ready.
- **Upload Artifact:** Uploads this `README.md` file as a downloadable workflow artifact named `project-doc`.
